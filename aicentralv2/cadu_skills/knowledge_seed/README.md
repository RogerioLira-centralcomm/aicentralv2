# Pacote inicial — Base Cadu

Importe cada arquivo como um documento separado em **Skills → Gestão → Base Cadu**.

Fluxo: completar fatos → registrar a fonte e a validade → salvar como rascunho → revisar → publicar.
Nunca publique placeholders, estimativas sem rótulo ou números sem fonte.

| Arquivo | Uso |
|---|---|
| `01-centralcomm-identidade.md` | identidade e posicionamento comuns a todos os Cadus |
| `02-servicos-e-solucoes.md` | soluções, critérios de indicação e limites comerciais |
| `03-canais-formatos-places.csv` | catálogo operacional para planejamento |
| `04-audiencias-e-programatica.csv` | sinais, ativação, qualidade e restrições de audiência |
| `05-cases-e-evidencias.csv` | provas aprovadas para propostas e defesas |

Para cada atualização, crie uma nova versão. O campo `status_fato` aceita `confirmado`, `estimativa`, `hipotese` ou `desatualizado`.
