# Contexto personalizável

Use somente os blocos fornecidos. Não preencha ausências com suposições silenciosas.

## Cliente

`client_id`, nome, segmento, praças, objetivos de negócio, políticas internas, fontes autorizadas.

## Marca

`brand_id`, posicionamento, proposta de valor, produtos, públicos, tom de voz, identidade visual, claims aprovados, termos obrigatórios, termos proibidos e ativos autorizados.

## Projeto

`project_id`, briefing, objetivo de comunicação, verba, período, conversão, KPIs, praça, restrições, canais obrigatórios/proibidos, entregáveis e responsáveis pela aprovação.

## Proveniência

Para cada fato importante, preserve `source`, `captured_at` e `confidence`. Em link público, mostre apenas o contexto marcado como compartilhável.
