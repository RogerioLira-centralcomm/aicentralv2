# Taste 16:9 — cena 1 (adapter CTV)

Fonte: Leonxlnx/taste-skill · imagegen-frontend-web.
Aqui a "seção" é uma placa 1920×1080, não uma landing.

Uma placa por cena. Sempre. Sem mosaico, sem contact sheet, sem página inteira num frame.

Não comece pelo hero esquerda-texto / direita-imagem. Primeiro tente:
- produto flutuando no preto (placa split)
- foto full-bleed com tipo na sombra (placa hero)
- lockup no eixo no fechamento (placa center)

Proibido neste still: glow roxo, blobs, cards SaaS, pílula de CTA, uppercase de label, menu de site, chrome de player, paisagem cinza desenhada.

Uma paleta só — a da marca. Tipo grande o bastante para TV. O HTML guarda as camadas; a foto não pinta headline nem logo inventada.

A primeira entrega é a cena 1. As outras cenas herdam a base e só mudam copy, key visual e se a logo está ligada.
