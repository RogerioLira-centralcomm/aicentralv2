O workspace do Cadu, acessível por agentes.

Um servidor MCP único para consultar projetos, produzir artefatos versionados e anexar fontes sem entregar ao agente acesso direto ao banco ou às regras internas do produto.

Como uma ação percorre o sistema

AgenteDeclara a intenção
MCPValida contrato e escopo
Serviço PythonAplica regras e créditos
ProjetoPersiste e versiona

O MCP é um adaptador. As regras de tenant, projeto, versões, arquivos e cobrança permanecem nos serviços Python compartilhados pelo chat e pelo frontend.

Conexão inicial

O endpoint é /workspace/mcp. A versão inicial usa JSON-RPC sobre HTTP e uma delegação assinada de cinco minutos, emitida por uma sessão autenticada no Cadu.

Emitir uma delegação

POST /workspace/api/v2/mcp-token
X-CSRF-Token: <csrf da sessão>
Content-Type: application/json

{
  "exposure": "customer_agent",
  "surface": "workspace"
}

Inicializar

POST /workspace/mcp
Authorization: Bearer <token>
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": { "protocolVersion": "2026-07-28" }
}
A delegação curta atende o Cadu e integrações iniciadas dentro do produto. OAuth, refresh token e revogação por aplicativo são requisitos anteriores à distribuição pública.

Artefatos versionados

Briefings, documentos, notas, resumos, planos, cenários e pesquisas nascem como rascunho. Uma atualização exige a versão conhecida pelo agente; se outra pessoa editar antes, o servidor recusa a gravação.

{
  "jsonrpc": "2.0",
  "id": 12,
  "method": "tools/call",
  "params": {
    "name": "artifacts.create_draft",
    "arguments": {
      "request_id": "0199dff8-85ac-72cc-81df-49d221884703",
      "type": "brief",
      "title": "Briefing da campanha",
      "content": { "objective": "Gerar demanda qualificada" }
    }
  }
}

artifacts.update_draft recebe expected_version e cria uma nova versão. Publicação não faz parte da v1 externa.

Um arquivo pode ser fonte — ou apenas anexo

Usar como fonte de dados

PDF, DOCX, TXT, CSV, Markdown, JSON e HTML têm o texto extraído, indexado e disponibilizado para pesquisa e respostas com contexto do projeto.

use_as_knowledge: true

Somente anexar

O arquivo permanece privado no projeto, mas seu conteúdo não é enviado ao índice nem utilizado como evidência automática. Imagens também podem seguir este caminho.

use_as_knowledge: false
A escolha é explícita em cada upload. O nome do arquivo ou seu formato nunca fazem o sistema presumir consentimento para usar o conteúdo como fonte.

Upload em duas etapas

Binários não atravessam o JSON-RPC. A ferramenta prepara uma autorização curta e o cliente envia o arquivo por multipart para o endpoint informado.

1. Preparar

tools/call → projects.prepare_source_upload

{
  "request_id": "0199dff8-85ac-72cc-81df-49d221884703",
  "use_as_knowledge": true
}

2. Enviar

POST /workspace/mcp/uploads
Authorization: Bearer <mesma delegação MCP>
Content-Type: multipart/form-data

upload_token=<token retornado>
file=@briefing.pdf

Limite inicial: 15 MB. Para indexação são aceitos PDF, DOCX e formatos textuais. Como simples anexo, também são aceitos PNG, JPEG, WebP e GIF.

Limites de segurança

TenantOrganização e usuário vêm do token assinado, nunca dos argumentos.
ProjetoO upload é vinculado ao projeto selecionado e o token expira em dez minutos.
ArquivosNome normalizado, limite de tamanho, extensão permitida e validação básica do conteúdo.
ConhecimentoSomente arquivos com consentimento explícito são extraídos e indexados.
CréditosA indexação usa o conector compartilhado do Cadu; anexar sem indexar não cobra processamento de IA.
MutaçãoAgentes externos criam e editam rascunhos; arquivamento continua restrito ao agente interno.

Studio será o próximo domínio assíncrono

A base está preparada para tools de estimativa, geração e consulta de jobs. Imagem e vídeo só serão publicados quando modelos, preços, armazenamento e política de reembolso estiverem estabilizados.

studio.image.estimate     studio.image.create
studio.video.estimate     studio.video.create
studio.jobs.get           studio.assets.attach_to_project

O Studio aplicará a estrutura de prompts do Cadu, reservará créditos, executará o provedor e devolverá um asset persistido. O prompt interno e as credenciais do provedor não serão expostos pelo MCP.

Limites conhecidos da v1

  • OAuth para aplicativos externos ainda não está disponível.
  • resources/list e resources/read ainda serão adicionados.
  • Upload de imagem como conhecimento visual/OCR ainda não está habilitado.
  • Publicação de artefatos e alterações do Planner permanecem internas.
  • Idempotência durável para mutações será adicionada antes da abertura pública.
