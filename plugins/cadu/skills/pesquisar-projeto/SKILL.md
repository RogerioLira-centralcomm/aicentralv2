# Pesquisar um projeto

1. Confirme o projeto. Use `projects.search_knowledge` e `projects.get_source_chunks` para buscar evidências.
2. Responda separando fatos (com a fonte e o trecho), lacunas e hipóteses. Nunca afirme que pesquisou o que a busca não retornou.
3. Para salvar trabalho: nota ou resumo em `projects.create_note`; documento editável em `artifacts.create_draft`, finalizando só após aprovação; link em `projects.create_link_reference`.
4. Mostre o que será salvo antes de gravar. Indexar uma fonte grande consome créditos: avise antes.
